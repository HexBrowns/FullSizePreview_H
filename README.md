# FullSizePreview_H マニュアル

**FullSizePreview_H** は、**空白キー**でプレビュー再生したときに、シーンを**等倍**で映す別ウィンドウを出す汎用プラグインです。
プレビュー編集画面は小さく縮めて表示されますが、このウィンドウでは 1920x1080 のシーンを 1920x1080 のまま確かめられます。

- **バージョン:** 0.6.1
- **作者:** by HexBrowns
- **必要環境:** AviUtl2 **2.1.10** 以上

本体が再生のために描いた画面をそのまま受け取って映すので、重いシーンでもプレビュー再生そのものを遅くしません。
増えるのは、読み出しの分の 1 フレームあたり数 ms だけです。
その数 ms で本体の再生が追いつかなくなるときは、フルサイズプレビューの更新を間引いて、本体の再生速度を優先します。

---

## 導入

1. [Releases](https://github.com/HexBrowns/FullSizePreview_H/releases) から `HexBrowns.FullSizePreview_H-v0.6.1.au2pkg.zip` をダウンロードし、AviUtl2のプレビューへドラッグ&ドロップする。
   手で置くなら、中の `Plugin` フォルダをAviUtl2のデータフォルダへコピーし、`Plugin\FullSizePreview_H\FullSizePreview_H.aux2` になるようにする。
2. AviUtl2を起動する。

v0.5.0 まではzipを展開して置く形でした。上書きで入れ替えて構いません。
v0.4.0 以前に置いた受け口は、消して置き直してください。

設定メニューはありません。**受け口を置いたシーンでだけ動きます**。

---

## 使い方

### 1. 受け口を置く（シーンごとに 1 回）

**編集** メニュー → **フルサイズプレビュー受け口を置く** を選ぶと、下の条件どおりに置かれます。

| シーンの状態 | 何が起きるか |
|------|------|
| 受け口が無い | 一番下のレイヤーの次に、フレーム 0 からシーンの最後まで置き、カメラ制御の対象から外す |
| 受け口がある | カメラ制御の対象から外す。受け口より下のレイヤーにオブジェクトが増えていたら、一番下へ移す |

置いた受け口は選択状態になります。
**元に戻す** 1 回で取り消せます。
受け口がシーンの一部にしか無いときや、2 個以上あるときはメッセージが出ます。
編集メニューの項目なので、ショートカットキーも割り当てられます。

手で置くときは、HexScriptの中のカスタムオブジェクト **フルサイズプレビュー受け口** を次のように置きます。
受け口は画面には何も描きません。

| 条件 | 理由 |
|------|------|
| タイムラインの一番下の、**レイヤー番号が一番大きいレイヤー**に置く | そこより番号の小さいレイヤーを全部描いた後の画面が届く。途中に置くと、それより下のレイヤーが映らない |
| **再生する範囲全体を覆う長さ**にする | 受け口が無いフレームでは画面が届かない |
| **カメラ制御の対象から外す** | カメラ制御の対象の中では、合成前の空の画面しか届かず、真っ黒になる。受け口を選び、設定欄の上の **カメラ制御の対象** ボタンを外す。メニューで置けば自動で外れる |

受け口は、ウィンドウが開いていないときは何もしません。置いたままでも編集やファイル出力は重くなりません。

**最新バージョンのVideoScope_Hでビデオスコープを出して再生しているときは、ウィンドウが開いていなくても画面を読み、ビデオスコープへ渡します**。
ビデオスコープの再生中の表示に、この受け口が必要です。

### 2. 空白キーで再生する

| 操作 | 結果 |
|------|------|
| 受け口があるシーンを**空白キー**で再生 | フルサイズプレビューが開く |
| 受け口が無いシーンを空白キーで再生 | 開かない |
| プレビュー再生ボタン / 右クリックメニューの **再生** | 開かない |
| 空白キーをもう一度押して再生を止める | 閉じる |
| フルサイズプレビューを**クリック** | 閉じる。再生は続く |

フルサイズプレビューはキーボードの入力を取らないので、開いたままでも空白キーなどのショートカットは本体に届きます。

## ウィンドウの大きさ

AviUtl2のメインウィンドウがあるモニターの中央に出ます。
大きさは**シーンの解像度とモニターの小さい方**です。
縦横比は保ち、拡大はしません。

| モニター | シーン | ウィンドウ |
|----------|--------|------------|
| 1920x1080 | 1920x1080 | 1920x1080 |
| 1920x1080 | 1280x720 | 1280x720 |
| 1920x1080 | 3840x2160 | 1920x1080 |

透明な部分には、シーンの背景色が敷かれます。
シーンがモニターより大きいときは、周りの画素を平均して縮めます。

- **出る場所と大きさは毎回この規則で決まります。** ドラッグで動かしたり、大きさを変えたりはできません。前の位置も覚えません
- **2 枚目のモニターには出せません。** AviUtl2のメインウィンドウがあるモニターに出ます。プレビューのウィンドウだけを別のモニターへ分離していても、メインウィンドウの側に出ます。別のモニターで見たいときは、AviUtl2のメインウィンドウをそのモニターへ移してください
- **ほかのアプリに切り替えると、フルサイズプレビューはそのアプリの後ろへ下がります**。再生は続きます。AviUtl2に戻ると、また一番手前に出ます

## 本体の再生が重いとき

フルサイズプレビューは、AviUtl2が再生のために描いた画面を、その都度読み出して受け取ります。
読み出しの時間はAviUtl2の描画に上乗せされます。
FHDで 1 フレームあたり数 ms、4K ではその数倍です。

**AviUtl2の再生が追いつかなくなったら、読み出しを間引きます**。
最大で 6 フレームに 1 回まで減らします。
AviUtl2のプレビュー再生の滑らかさを優先し、フルサイズプレビューの方がコマ送りのようになります。
シーンが軽くなって追いつけば、自動で毎フレームに戻ります。

- AviUtl2が余裕で再生できる軽いシーンでは間引きません
- 読み出しを止めても速くならないほどAviUtl2自身が重いときは、読み出しが 1 フレームの 5% を超える分だけ間引きます
- 間引いたかどうかは、`Log` フォルダのログの「読み出しをNフレームに 1 回へ間引きます」の行と、閉じたときの行の「間引きN回」で分かります

## 注意事項・既知の制限

- **受け口は再生するシーンにだけ置いてください。** シーンオブジェクトで読み込んでいる別のシーンにも置くと、そちらの画面が混ざります
- **再生の速さは本体と同じです。** 本体のプレビュー再生がコマ落ちするシーンでは、フルサイズプレビューも同じだけコマ落ちします
- 再生位置は、再生を始めた時刻からの経過時間で数えています。**再生速度**を変えたときは、AviUtl2を再起動するまで古い速度で数えることがあります
- 受け口に届く画面が最初から空のときは、ウィンドウに案内が出ます。多くはカメラ制御の対象に入っていることが原因です。案内が出ている間は、読み出しを 0.5 秒に 1 回に減らします
