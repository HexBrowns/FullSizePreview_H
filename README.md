# FullSizePreview_H マニュアル

**FullSizePreview_H** は、**空白キー**でプレビュー再生したときに、シーンを**等倍**で映す別ウィンドウを出すプラグイン（Rust 製 `.aux2`）です。プレビュー編集画面は小さく縮めて表示されますが、このウィンドウでは 1920x1080 のシーンを 1920x1080 のまま確かめられます。

- **バージョン:** 0.6.1（2026-10-10: 本体の再生が重くなったときは、フルサイズプレビューの更新を間引いて本体の再生速度を優先するようにした。4K のシーンを小さいモニターで見るときの縮小を軽くした。ほかのアプリに切り替えたら、そのアプリを覆わないようにした。0.6.0: 受け口が、ビデオスコープ（VideoScope_H）にも再生中の画面を渡すようにした。0.5.1: フルサイズプレビューをクリックで閉じた直後に AviUtl2 を終了・再起動すると落ちることがあったのを直した。使い方は変わらない。0.5.0 で受け口がフィルタオブジェクトからカスタムオブジェクトに変わった。0.4.0 以前に置いた受け口は消して置き直す）
- **作者:** by HexBrowns
- **必要環境:** AviUtl2 **2.1.10** 以上（2.1.11 で確認）

本体が再生のために描いた画面をそのまま受け取って映すので、重いシーンでもプレビュー再生そのものを遅くしません（読み出しの分、1 フレームあたり数 ms だけ増えます）。
その数 ms で本体の再生が追いつかなくなるときは、フルサイズプレビューの更新を間引いて、本体の再生速度を優先します（下の「本体の再生が重いとき」）。

## 導入

1. [Releases](https://github.com/HexBrowns/FullSizePreview_H/releases) から `HexBrowns.FullSizePreview_H-v0.6.1.au2pkg.zip` をダウンロードし、AviUtl2 のプレビューへドラッグ&ドロップする
   （手で置くなら、中の `Plugin` フォルダを AviUtl2 のデータフォルダ（既定は `C:\ProgramData\aviutl2`）へコピーする。`Plugin\FullSizePreview_H\FullSizePreview_H.aux2` になる）
2. AviUtl2 を再起動する

v0.5.0 までは zip を展開して置く形でした。上書きで入れ替えて構いません。

設定メニューはありません。**受け口を置いたシーンでだけ動きます**（下記）。

### ビルド（開発者向け）

リポジトリのルートで [aviutl2-cli](https://github.com/sevenc-nanashi/aviutl2-cli) の `au2` を実行します。
`release/` に、AviUtl2 のプレビューへドラッグ&ドロップして導入できるパッケージ（`.au2pkg.zip`）ができます。

```powershell
au2 release
```

## 使い方

### 1. 受け口を置く（シーンごとに 1 回）

**編集** メニュー → **フルサイズプレビュー受け口を置く**（レイヤーの何も無いところの右クリックメニューにもあります）を選ぶと、下の条件どおりに置かれます。

| シーンの状態 | 何が起きるか |
|------|------|
| 受け口が無い | 一番下のレイヤーの次に、フレーム 0 からシーンの最後まで置き、カメラ制御の対象から外す |
| 受け口がある | カメラ制御の対象から外す。受け口より下のレイヤーにオブジェクトが増えていたら、一番下へ移す |

置いた受け口は選択状態になります。**元に戻す**（Ctrl+Z）1 回で取り消せます。受け口がシーンの一部にしか無いときや、2 個以上あるときはメッセージが出ます。
編集メニューの項目なので、ショートカットキーも割り当てられます。

手で置くときは、カスタムオブジェクト **フルサイズプレビュー受け口**（ラベル **HexScript**）を次のように置きます。受け口は画面には何も描きません。

| 条件 | 理由 |
|------|------|
| **レイヤー番号が一番大きいレイヤー**（タイムラインの一番下）に置く | そこより番号の小さいレイヤーを全部描いた後の画面が届く。途中に置くと、それより下のレイヤーが映らない |
| **再生する範囲全体を覆う長さ**にする | 受け口が無いフレームでは画面が届かない |
| **カメラ制御の対象から外す** | カメラ制御の対象の中では、合成前の空の画面しか届かない（真っ黒になる）。受け口を選び、設定欄の上の **カメラ制御の対象** ボタンを外す。メニューで置けば自動で外れる |

受け口は、ウィンドウが開いていないときは何もしません。置いたままでも編集やファイル出力は重くなりません。

**ビデオスコープ（VideoScope_H v0.2.0 以降）を出して再生しているときは、ウィンドウが開いていなくても画面を読み、ビデオスコープへ渡します**（1 秒に 10 枚まで）。ビデオスコープの再生中の表示に、この受け口が要ります。

### 2. 空白キーで再生する

| 操作 | 結果 |
|------|------|
| **空白キー**で再生（受け口あり） | フルサイズプレビューが開く |
| 空白キーで再生（受け口なし） | 開かない |
| プレビュー再生ボタン / 右クリックメニューの **再生** | 開かない（いつもどおり本体のプレビューだけ） |
| 空白キーをもう一度押す（再生を止める） | 閉じる |
| フルサイズプレビューを**クリック** | 閉じる（再生は続く） |

フルサイズプレビューはキーボードの入力を取らないので、開いたままでも空白キーなどのショートカットは本体に届きます。

## ウィンドウの大きさ

AviUtl2 のメインウィンドウがあるモニターの中央に出ます。大きさは**シーンの解像度とモニターの小さい方**です（縦横比は保ち、拡大はしません）。

| モニター | シーン | ウィンドウ |
|----------|--------|------------|
| 1920x1080 | 1920x1080 | 1920x1080（画面いっぱい） |
| 1920x1080 | 1280x720 | 1280x720（等倍、余白なし） |
| 1920x1080 | 3840x2160 | 1920x1080（縮小） |

透明な部分には、シーンの背景色が敷かれます。シーンがモニターより大きいときは、周りの画素を平均して縮めます（細い線もちらつきにくい縮め方です）。

- **出る場所と大きさは毎回この規則で決まります。** ドラッグで動かしたり、大きさを変えたりはできません。前の位置も覚えません
- **2 枚目のモニターには出せません。** AviUtl2 のメインウィンドウがあるモニターに出ます。プレビューのウィンドウだけを別のモニターへ分離していても、メインウィンドウの側に出ます。別のモニターで見たいときは、AviUtl2 のメインウィンドウをそのモニターへ移してください
- **ほかのアプリに切り替えると（Alt+Tab など）、フルサイズプレビューはそのアプリの後ろへ下がります**（再生は続きます）。AviUtl2 に戻ると、また一番手前に出ます

## 本体の再生が重いとき

フルサイズプレビューは、AviUtl2 が再生のために描いた画面を、その都度読み出して受け取ります。読み出しの時間（FHD で 1 フレームあたり数 ms、4K ではその数倍）は AviUtl2 の描画に上乗せされます。

**AviUtl2 の再生が追いつかなくなったら、読み出しを間引きます**（2 フレームに 1 回、3 フレームに 1 回 … 最大 6 フレームに 1 回）。
AviUtl2 のプレビュー再生の滑らかさを優先し、フルサイズプレビューの方がコマ送りのようになります。シーンが軽くなって追いつけば、自動で毎フレームに戻ります。

- 軽いシーン（AviUtl2 が余裕で再生できるとき）は間引きません
- AviUtl2 自身が重くて追いつかない（読み出しを止めても速くならない）ときは、読み出しが 1 フレームの 5% を超える分だけ間引きます
- 間引いたかどうかは、ログ（`Log` フォルダ）の「読み出しを N フレームに 1 回へ間引きます」の行と、閉じたときの行の「間引き N 回」で分かります

## 注意事項・既知の制限

- **受け口は再生するシーンにだけ置いてください。** シーンオブジェクトで読み込んでいる別のシーンにも置くと、そちらの画面が混ざります
- **再生の速さは本体と同じです。** 本体のプレビュー再生がコマ落ちするシーンでは、フルサイズプレビューも同じだけコマ落ちします
- 再生位置は、再生を始めた時刻からの経過時間で数えています。**再生速度**を変えたときは、AviUtl2 を再起動するまで古い速度で数えることがあります（本体が設定を書き戻す時期を確かめていないため）
- 受け口に届く画面が最初から空のときは、ウィンドウに案内が出ます（多くはカメラ制御の対象に入っているため）。案内が出ている間は、読み出しを 0.5 秒に 1 回に減らします
