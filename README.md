# FullSizePreview_H マニュアル

**FullSizePreview_H** は、**空白キー**でプレビュー再生したときに、シーンを**等倍**で映す別ウィンドウを出すプラグイン（Rust 製 `.aux2`）です。プレビュー編集画面は小さく縮めて表示されますが、このウィンドウでは 1920x1080 のシーンを 1920x1080 のまま確かめられます。

- **バージョン:** 0.5.0（受け口がフィルタオブジェクトからカスタムオブジェクトに変わった。0.4.0 以前に置いた受け口は消して置き直す）
- **作者:** by HexBrowns
- **必要環境:** AviUtl2 **2.1.10** 以上（2.1.11 で確認）

本体が再生のために描いた画面をそのまま受け取って映すので、重いシーンでもプレビュー再生そのものを遅くしません（読み出しの分、1 フレームあたり数 ms だけ増えます）。

---

## 導入

1. [Releases](https://github.com/HexBrowns/FullSizePreview_H/releases) の zip を展開し、中の `Plugin` フォルダを AviUtl2 のデータフォルダ（既定は `C:\ProgramData\aviutl2`）へコピーする（`Plugin\FullSizePreview_H\FullSizePreview_H.aux2` になる）
2. AviUtl2 を再起動

設定メニューはありません。**受け口を置いたシーンでだけ動きます**（下記）。

### ビルド（開発者向け）

```powershell
cd AI\plugins\FullSizePreview_H
.\build.ps1
```

---

## 使い方

### 1. 受け口を置く（シーンごとに 1 回）

**編集** メニュー → **フルサイズプレビュー受け口を置く**（レイヤーの何も無いところの右クリックメニューにもあります）を選ぶと、下の条件どおりに置かれます。

| シーンの状態 | 何が起きるか |
|------|------|
| 受け口が無い | 一番下のレイヤーの次に、フレーム 0 からシーンの最後まで置き、カメラ制御の対象から外す |
| 受け口がある | カメラ制御の対象から外す。受け口より下のレイヤーにオブジェクトが増えていたら、一番下へ移す |

置いた受け口は選択状態になります。**元に戻す**（Ctrl+Z）1 回で取り消せます。受け口がシーンの一部にしか無いときや、2 個以上あるときはメッセージが出ます。
編集メニューの項目なので、ショートカットキーも割り当てられます。

手で置くときは、カスタムオブジェクト **フルサイズプレビュー受け口**（ラベル **HexScript**）を次のように置きます。受け口は画面には何も描きません。

| 条件 | 理由 |
|------|------|
| **レイヤー番号が一番大きいレイヤー**（タイムラインの一番下）に置く | そこより番号の小さいレイヤーを全部描いた後の画面が届く。途中に置くと、それより下のレイヤーが映らない |
| **再生する範囲全体を覆う長さ**にする | 受け口が無いフレームでは画面が届かない |
| **カメラ制御の対象から外す** | カメラ制御の対象の中では、合成前の空の画面しか届かない（真っ黒になる）。受け口を選び、設定欄の上の **カメラ制御の対象** ボタンを外す。メニューで置けば自動で外れる |

受け口は、ウィンドウが開いていないときは何もしません。置いたままでも編集やファイル出力は重くなりません。

### 2. 空白キーで再生する

| 操作 | 結果 |
|------|------|
| **空白キー**で再生（受け口あり） | フルサイズプレビューが開く |
| 空白キーで再生（受け口なし） | 開かない |
| プレビュー再生ボタン / 右クリックメニューの **再生** | 開かない（いつもどおり本体のプレビューだけ） |
| 空白キーをもう一度押す（再生を止める） | 閉じる |
| フルサイズプレビューを**クリック** | 閉じる（再生は続く） |

フルサイズプレビューはキーボードの入力を取らないので、開いたままでも空白キーなどのショートカットは本体に届きます。

## ウィンドウの大きさ

AviUtl2 のメインウィンドウがあるモニターの中央に出ます。大きさは**シーンの解像度とモニターの小さい方**です（縦横比は保ち、拡大はしません）。

| モニター | シーン | ウィンドウ |
|----------|--------|------------|
| 1920x1080 | 1920x1080 | 1920x1080（画面いっぱい） |
| 1920x1080 | 1280x720 | 1280x720（等倍、余白なし） |
| 1920x1080 | 3840x2160 | 1920x1080（縮小） |

透明な部分には、シーンの背景色が敷かれます。

## 注意事項・既知の制限

- **受け口は再生するシーンにだけ置いてください。** シーンオブジェクトで読み込んでいる別のシーンにも置くと、そちらの画面が混ざります
- **再生の速さは本体と同じです。** 本体のプレビュー再生がコマ落ちするシーンでは、フルサイズプレビューも同じだけコマ落ちします
- 再生位置は、再生を始めた時刻からの経過時間で数えています。**再生速度**を変えたときは、AviUtl2 を再起動するまで古い速度で数えることがあります（本体が設定を書き戻す時期を確かめていないため）
- 受け口に届く画面が最初から空のときは、ウィンドウに案内が出ます（多くはカメラ制御の対象に入っているため）
